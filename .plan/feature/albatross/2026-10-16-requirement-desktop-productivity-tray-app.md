# 요구사항: Windows/macOS 생산성 트레이 앱

## 작업 목표

Windows와 macOS에서 동작하는 상주형(트레이/메뉴바) 생산성 도구를 만든다. Raycast·Magnet·클립보드 매니저·키 리매퍼(Karabiner/AutoHotkey류)의 핵심 기능을 하나의 앱으로 제공한다.

- **MVP**: 앱/사이트 실행 단축키, 창 크기·위치 조절, 클립보드 히스토리
- **후속 단계**: 텍스트 스니펫, 키 리매핑/매크로

성공 조건: Windows에서 MVP 3개 기능이 아래 요구사항대로 동작하고, 후속 단계와 macOS 포팅이 구조 변경 없이 추가될 수 있다.

## 배경 및 맥락

- 저장소는 빈 상태(Initial commit)에서 시작한다.
- 사용 대상은 본인/팀 내부이며 공개 배포하지 않는다.
- 현재 개발 환경은 Windows 11이다. macOS는 Windows 완성 후 포팅한다.

## 요구사항

### 공통

1. 앱은 트레이(Windows) / 메뉴바(macOS)에 상주한다. 트레이 메뉴에서 설정 창 열기와 종료를 할 수 있다.
2. 모든 기능 설정은 설정 창에서 한다. 통합 검색 런처 창은 없다.
3. 설정 창에서 기능(실행 단축키, 창 조절, 클립보드, 스니펫, 키 리매핑)별로 켜기/끄기를 할 수 있다.
4. 설정은 OS 사용자 설정 폴더(Windows `%APPDATA%`, macOS `~/Library/Application Support`)의 `settings.json`에 저장한다.
5. 설정을 파일로 내보내기/가져오기할 수 있다. OS마다 다른 값(앱 실행 경로 등)은 OS별로 구분해 저장해, 다른 OS에서 가져와도 해당 OS의 값만 적용된다.
6. 로그인 시 자동 실행을 설정에서 켜고 끌 수 있으며 기본값은 켬이다.
7. 단축키 충돌 처리:
   - 앱 내부의 다른 단축키와 겹치면 경고하고 저장을 막는다.
   - OS 전역 단축키 등록이 실패하면(다른 앱이 선점) 해당 항목에 오류를 표시하고, 앱 시작 시 실패 항목이 있으면 트레이 알림을 띄운다.

### MVP 1. 앱/사이트 실행 단축키

1. 사용자는 전역 단축키와 대상(앱 또는 URL)을 짝지어 등록·수정·삭제할 수 있다.
2. 앱 대상 선택: 설치된 앱 목록(Windows 시작 메뉴, macOS Applications)을 검색해 고르거나, 실행 파일(exe/바로가기/.app)을 파일 대화상자로 직접 고른다.
3. 앱 단축키 동작:
   - 앱이 실행 중이 아니면 실행한다.
   - 실행 중이지만 포커스가 없으면 그 앱 창을 앞으로 가져온다.
   - 이미 포커스 상태면 최소화(숨김)한다.
4. URL 단축키는 기본적으로 OS 기본 브라우저로 연다. 항목별로 브라우저 실행 파일을 지정할 수 있으며, 지정하면 그 브라우저로 연다.

### MVP 2. 창 크기·위치 조절 (Magnet류)

1. 포커스된 창에 단축키로 다음 배치를 적용한다: 좌/우/상/하 반쪽, 네 귀퉁이 1/4, 1/3·2/3, 최대화, 가운데 정렬, 다음 모니터로 이동.
2. 배치 기준은 해당 모니터의 작업 영역(작업 표시줄/Dock·메뉴바 제외)이다.
3. 멀티모니터를 지원한다.
4. 기본 단축키는 Rectangle 스타일 프리셋으로 제공하며 모두 수정할 수 있다.
   - Windows 예: Ctrl+Alt+←/→/↑/↓(반쪽), Ctrl+Alt+U/I/J/K(1/4), Ctrl+Alt+Enter(최대화), Ctrl+Alt+C(가운데), Ctrl+Alt+Win+→(다음 모니터)
   - macOS: 위 Ctrl+Alt를 Ctrl+Option으로 대응
   - 1/3·2/3 기본 키는 Rectangle 프리셋을 따른다.

### MVP 3. 클립보드 히스토리

1. 텍스트, 이미지, 파일 경로(탐색기/Finder에서 복사한 파일 목록)를 기록한다.
2. 기록은 디스크(SQLite)에 저장해 재시작 후에도 유지된다. 이미지는 파일로 저장하고 DB에는 참조를 둔다.
3. 최대 보관 개수를 설정할 수 있으며 기본값은 500이다. 초과하면 오래된 항목부터 삭제한다.
4. 항목을 핀으로 고정할 수 있다. 고정 항목은 개수 초과 삭제 대상에서 제외된다.
5. 개별 항목 삭제와 전체 삭제(고정 제외)를 할 수 있다.
6. 이미 기록된 것과 같은 내용을 다시 복사하면 새 항목을 추가하지 않고 기존 항목을 맨 위로 올린다.
7. 이미지 최대 크기를 설정할 수 있으며 기본값은 10MB다. 초과하는 이미지는 기록하지 않는다.
8. 전역 단축키(기본 Windows Ctrl+Shift+V, macOS Cmd+Shift+V)로 팝업 목록을 연다.
   - 팝업은 마우스 커서가 있는 모니터의 중앙에 표시한다.
   - 타이핑하면 목록이 필터링된다.
   - 이미지는 썸네일로 표시한다.
   - Enter로 선택한 항목을 팝업을 열기 직전의 창에 바로 붙여넣는다.
   - Esc로 닫는다.
9. 민감 정보(비밀번호 관리자 등)에 대한 특별 처리는 하지 않는다. 모든 복사를 기록한다.

### 후속 1. 텍스트 스니펫

1. 사용자는 키워드와 정적 텍스트를 짝지어 등록·수정·삭제할 수 있다.
2. 어느 앱에서든 키워드 입력이 완성되는 즉시(구분자 입력 없이) 키워드를 지우고 텍스트로 치환한다.
3. 삽입은 클립보드에 텍스트를 넣고 붙여넣은 뒤 원래 클립보드 내용을 복원하는 방식이다. 이 임시 복사는 클립보드 히스토리에 기록하지 않는다.
4. 키워드는 영문·숫자·기호로 구성한다(예: `;addr`). 한글 IME 조합 중 입력은 감지 대상이 아니다.

### 후속 2. 키 리매핑/매크로

1. 다음 규칙 유형을 지원한다.
   - 단일 키 → 키 (예: CapsLock → Esc)
   - 모디파이어 레이어 (예: CapsLock+H/J/K/L → 방향키, CapsLock → Hyper 키(Ctrl+Alt+Shift+Win/Cmd))
   - 탭/홀드 구분 (예: CapsLock 탭은 Esc, 홀드는 Ctrl)
   - 키 시퀀스 매크로: 하나의 조합키에 여러 키 입력을 순서대로 실행
2. 규칙은 전역으로 적용한다.
3. 제외 앱 목록을 둘 수 있으며, 목록에 있는 앱이 포커스일 때는 리매핑이 동작하지 않는다.

## 제외 범위

- Raycast식 통합 검색 런처 창
- 창 드래그 스냅(화면 가장자리로 끌어 배치)
- 클립보드 민감 정보 필터링, 제외 앱, DB 암호화
- 스니펫 동적 변수(날짜, 클립보드, 커서 위치, 입력 폼), 스니펫 검색 팝업, 구분자 입력 후 치환
- 앱별 조건부 리매핑 규칙(제외 목록 외)
- 트레이 전체 일시정지
- 코드 서명, macOS 공증, 자동 업데이트, 설치 파일 공개 배포, 다국어
- 클라우드 동기화
- 브라우저 프로필 지정

## 미결정 사항

요구사항 차원의 미결정 질문은 남아 있지 않다.

## 기타 사항

- Windows에서 관리자 권한으로 실행된 창에는 비관리자 앱의 키 입력 주입(자동 붙여넣기, 스니펫, 리매핑)이 막힐 수 있다(UIPI). 확인된 사실은 아니며 구현 시 검증하고 결과를 기록한다.
- macOS는 창 제어, 키 감시, 키 주입을 위해 손쉬운 사용(Accessibility)과 입력 모니터링 권한이 필요하다. 포팅 단계에서 권한 안내 흐름을 다룬다.
